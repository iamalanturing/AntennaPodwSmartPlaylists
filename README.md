# AntennaPod — Smart Playlists fork

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

This is **AntennaPodwSmartPlaylists**, a personal fork of
[AntennaPod](https://github.com/AntennaPod/AntennaPod), the open-source podcast manager for
Android. It adds rule-based Smart Queues (auto-generated playlists that match a set of rules,
such as podcast, tag or media type) and a home-screen widget for them.

**This fork is not affiliated with, endorsed by, or supported by the AntennaPod team.** If you
want the official, unmodified app, get it from
[Google Play](https://play.google.com/store/apps/details?id=de.danoeh.antennapod) or
[F-Droid](https://f-droid.org/app/de.danoeh.antennapod), and use the
[AntennaPod Forum](https://forum.antennapod.org/) or
[official issue tracker](https://github.com/AntennaPod/AntennaPod/issues) for it — not this repo.
